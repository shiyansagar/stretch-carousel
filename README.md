# Stretch Carousel

A three.js card carousel with a screen-space lens: cards stay sharp in the centre and stretch, flare and grow a rainbow rim toward the edges.

- Drag, scroll or use the arrow keys to move.
- Press **G** to show or hide the parameters panel. Double-click a slider to reset it; **Copy** exports the settings as JSON.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Pushing to `main` builds the site and publishes it to GitHub Pages via `.github/workflows/deploy.yml`.
